This project documents how I web-scrape all U.S. congressional speeches on the 2019 Hong Kong protest movements and applied BERTopic models to classify the individual texts into different topics.<br>
[Webscrape](webscrape_congress_hk.ipynb): Web scraping with Selenium, on [Congress.gov](https://www.congress.gov/congressional-record)<br>
[BERTopic](bertopic_model_hk.ipynb): Apply Bidirectional Encoder Representations from Transformers (BERT) models to classify the topics of each speech.
